# Roteiro do vídeo

1. Apresentação do trabalho e da tecnologia (Business Intelligence / Apache Superset).
2. Estrutura do repositório e `docker-compose.yml` (MySQL + Superset).
3. `docker compose up -d` e `docker compose ps` mostrando o MySQL *healthy*.
4. Contagem das tabelas no MySQL (usuario, filme, avaliacao, genero, filme_genero).
5. Login no Superset e conexão com a base (`Settings → Database Connections`).
6. SQL Lab: execução das consultas de `sql/consultas.sql`.
7. Dashboard: KPIs, nota média por gênero, avaliações por mês, por faixa etária e sexo, top 10 filmes.
8. Exportação do dashboard para `export/`.
9. Conclusão.
